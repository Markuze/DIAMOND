\section{Related Work}
\label{sec:related}

\paragraph{Shared I/O data.} Fbufs shares pages across protection domains through
mappings~\cite{fbufs}. IO-Lite extends that idea with immutable buffers shared among
applications, networking and the file cache~\cite{iolite}. PASTE lets an application
retain received buffers as stored values and includes a kernel TCP path~\cite{paste}.
\sys applies checked handle operations to existing kernel I/O paths. It also lends
writable pages from an eligible I/O area, with the same object bounds and lifetime rules.

\paragraph{Writable I/O memory.} MAIO preserves kernel TCP and separates mapped I/O
memory from kernel control state~\cite{maio}. Header splitting protects the headers
used by the kernel, and receive rings can separate applications. Its privileged
configuration allows device-wide access. \sys also supports device-wide trust and
uses software copies of protocol headers and driver control fields to protect the
state the kernel relies on. Object handles add explicit retention and reuse.

\paragraph{Storage and networking.} \sendfile sends file ranges, and \splice and
\code{tee} move or share data through pipes~\cite{sendfileapi,spliceapi}. Registered
buffers compose with direct I/O and zero-copy sends~\cite{sendzcdoc}. ublk lets a
userspace block server refer to kernel I/O request buffers using registered
indices~\cite{ublkzc}. These systems already avoid copies on storage and network paths.
\sys lets a single store name completed data from different endpoints and carry those
names across later operations, subject to each endpoint's permissions and layout.

\paragraph{In-kernel forwarding and transparent access.} Kernel-assisted forwarding
predates \sys~\cite{rosu03}. BMC handles eligible UDP cache requests in the kernel, and
BPF-Broker fans out UDP publications~\cite{bmc,bpfbroker}. Libra anchors proxy payload
for forwarding while keeping the socket API~\cite{libra}. zIO tracks data in
unmodified applications to eliminate unnecessary copies~\cite{zio}. These systems
specialize a path or preserve an existing programming interface. \sys exposes
explicit retention and destination choice to application logic through handles.
